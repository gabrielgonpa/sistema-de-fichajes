# 🕒 Sistema de Fichajes

Interfaz de fichaje de empleados conectada a una base de datos.  
- 👤 **Empleados:** pueden ver sus horas registradas.  
- 🛠️ **Administradores:** pueden gestionar y editar fichajes.
